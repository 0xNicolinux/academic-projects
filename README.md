# 🎓 Academic Projects

> Uma coleção de projetos, desafios e exercícios desenvolvidos ao longo da minha jornada acadêmica.

Este repositório reúne projetos desenvolvidos durante minha graduação e estudos na área de tecnologia. Aqui estão exercícios, desafios e pequenas aplicações que representam diferentes momentos do meu aprendizado e da minha evolução como desenvolvedor.

A ideia não é apenas guardar códigos finalizados, mas também registrar o processo: aprender algo novo, errar, refazer e descobrir maneiras melhores de resolver problemas.

## 🚧 Sobre este repositório

Este é um repositório em constante construção. Alguns projetos são simples, outros mais completos — e isso é intencional.

Eles representam diferentes etapas da minha jornada. Conforme continuo aprendendo, novos projetos serão adicionados e os antigos permanecerão aqui como um registro de onde comecei.
